📚 වචන 3ක් මතක තියාගන්න

1⭐ Star = Like එක. "මේක පට්ට!" කියලා දාන එක

2🍴 Fork = Copy එක. මේ repo එකේ copy එකක් ඔයාගේ account එකට ගන්න එක

3🚀 PR (Pull Request) = "අයියේ මම අලුත් දෙයක් හැදුවා, එකතු කරගන්න" කියලා එවන request එක

🗺️ Step by Step - කොහොමද කරන්නේ?

1 Star දාමු

GitHub එකේ උඩ ⭐ Star button එක ඔබන්න.

2 Fork කරන්න

GitHub එකේ උඩ දකුණේ Fork > Create Fork ඔබන්න. දැන් ඔයාට copy එකක් ලැබෙනවා!

3 ඔයාගේ file එක හදමු - Main එක!

1. Fork කරපු repo එකේ students/ folder එකට යන්න
2. Add file > Create new file
3. නම: oyage-nama.md (උදා: sukitha.md)
4. ඇතුලේ මේ වගේ දාන්න:

# මම සුඛිත 😎 - ඉන්නේ: කොළඹ - ඉගෙන ගන්නේ: 10 වසර - ආස දේ: Gaming & Coding - හීනය: Game Developer කෙනෙක් වෙනවා!

5. පහල Commit changes ඔබන්න

4 Pull Request දාමු!

1. ඔයාගේ repo එකේ උඩ Contribute > Open Pull Request
2. Title: "Add my profile"
3. Create Pull Request ඔබන්න

🎉 සුබ පැතුම්! ඔයා දැන් Open Source Developer කෙනෙක්!
