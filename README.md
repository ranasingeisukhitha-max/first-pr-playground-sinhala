### 🚀 කොහොමද එකතු වෙන්නේ? (විනාඩි 2යි)

**Step 1:** මේ Repo එක Fork කරන්න
**Step 2:** `students/` folder එකේ `ඔයාගේ-nama.md` file එකක් හදන්න
**Step 3:** මෙහෙම ලියන්න:
- Name: ඔයාගේ නම
- School: ඉස්කෝලේ
- Hobby: කැමති දෙයක්
- Goal: මොකක්ද වෙන්න ඕන
- GitHub: username එක

**Step 4:** Pull Request දාන්න. අපි Accept කරනවා! ✅
